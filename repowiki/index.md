# NeKiro A2A Transport RepoWiki

This is the bilingual reading surface for the reusable A2A HTTP, JSON-RPC,
and SSE transport mechanics. The transport README remains canonical; MkDocs
renders it in CI.

## Start here

- [Source documentation](source-docs/index.md) — scope, compatibility, usage, and verification.
- [GitHub repository](https://github.com/NeKiro-project/nekiro-a2a-transport-go) — source, issues, and releases.
- [Core RepoWiki](https://nekiro-project.github.io/NeKiro/) — platform contracts and architecture.

This module does not own discovery, endpoint selection, credentials,
authorization, retry, fallback, persistence, Ledger behavior, or an Agent
Runtime.
